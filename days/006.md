# Day 006 - Create a Cron Job

## 🎯 Objective

Create and manage a cron job to automate recurring tasks.

---

## Install Cronie

```bash
sudo yum install cronie -y
```

---

## Start & Enable Crond / Confirm Status

```bash
sudo systemctl start crond
sudo systemctl enable crond
sudo systemctl status crond
```

--

## Add New Cron Job

```bash
crontab -e
```

Add cronjob:
5 * * * * echo "Hello World!"
:wq!

---

## Validate

```bash
crontab -l
```
