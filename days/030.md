# Day 030 - Git Hard Reset

## 🎯 Objective

The repository has accumulated unwanted test commits. Clean up the history by resetting `HEAD` back to a known-good commit and force-pushing the result to the remote.

---

## Connect to the Storage Server

```bash
ssh natasha@ststor01
```

---

## Navigate to the Repository

```bash
cd /usr/kodekloudrepos/blog
```

---

## Review Commit History

```bash
git log --oneline
```

Identify the commit hash for the commit with message `add data.txt file`.

---

## Reset HEAD to the Target Commit

```bash
git reset --hard <commit-hash>
```

---

## Verify the History

```bash
git log --oneline
```

Confirm the history now ends at the `add data.txt file` commit.

---

## Force-Push the Cleaned History

```bash
git push origin master --force
```

---
