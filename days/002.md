# Day 002 - Temporary User Setup with Expiry (useradd, chage)

**100 Days of DevOps, Day 2:** how to create a temporary Linux user account and set an automatic expiration date using `useradd` and `chage`, so temporary access closes itself out without manual cleanup.

## 🎯 Objective

Create a temporary Linux user account with an expiration date, then verify and manage that expiration using `chage`.

---

## Why This Matters

Temporary accounts — for contractors, auditors, or short-term project access — are a common source of security debt when nobody remembers to disable them. Setting an expiration date with `chage -E` at creation time means the account locks itself out automatically, without relying on a human to remember weeks or months later. This is a standard control in compliance frameworks like SOC 2 and ISO 27001, where lingering unused accounts are a frequent audit finding.

---

## Create a Temporary User

```bash
sudo useradd tempuser
sudo passwd tempuser
```

`useradd tempuser` creates the account and `passwd tempuser` sets its initial password, exactly as with any standard Linux user.

---

## Set an Expiration Date

```bash
sudo chage -E 2026-12-31 tempuser
```

`chage -E` sets the account's expiration date. Once that date passes, the account is automatically disabled — no cron job or manual step required.

---

## Verify the Expiration Date

```bash
sudo chage -l tempuser
```

`chage -l` prints the account's password and expiration policy, confirming the expiration date was applied correctly.

---

## Remove the Expiration Date (Optional)

```bash
sudo chage -E -1 tempuser
```

Passing `-1` clears the expiration date, turning the temporary account back into a standard, non-expiring one — useful if a short-term engagement gets extended.

---

## Key Takeaways

- `useradd` + `chage -E` is the fastest way to provision a self-expiring Linux account.
- `chage -l` is the go-to command for auditing an account's password and expiration policy.
- Setting `-E -1` removes an expiration date if a temporary account needs to become permanent.
- Automatic account expiration reduces the risk of forgotten, unused accounts lingering as an attack surface.
