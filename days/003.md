# Day 003 - Secure Root SSH Access

## 🎯 Objective

Disable direct root SSH login and use a regular user with `sudo` for administration.

---

## Check Root Login Status

```bash
cat /etc/ssh/sshd_config | grep PermitRootLogin
```

---

## Disable Root SSH Login

Edit the SSH configuration:

```bash
sudo vim /etc/ssh/sshd_config
```

Set:

```text
PermitRootLogin no
```

---

## Restart SSH Service

Ubuntu:

```bash
sudo systemctl restart ssh
```

RHEL/CentOS:

```bash
sudo systemctl restart sshd
```

---

## Test SSH Access

Try logging in as root:

```bash
ssh root@<server-ip>
```

Expected result:

```text
Permission denied.
```
