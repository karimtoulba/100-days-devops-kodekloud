# Day 033 - Resolve Git Merge Conflicts

## 🎯 Objective

Sarah and Max have both been editing the same story file. Push Max's local changes, resolve the resulting merge conflict, and fix a typo in the process.

---

## Connect to the Storage Server

```bash
ssh max@ststor01
```

```
Password: Max_pass123
```

---

## Navigate to the Repository

```bash
cd ~/story-blog
```

---

## Attempt to Push Local Changes

```bash
git add .
git commit -m "Update story-index.txt"
git push origin master
```

The push is rejected because Sarah's changes already exist upstream.

---

## Pull and Trigger the Merge

```bash
git pull origin master
```

Git pauses and marks `story-index.txt` as conflicted.

---

## Resolve the Conflict

```bash
vim story-index.txt
```

Remove the conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`) and fix the typo:

```
Mooose -> Mouse
```

---

## Stage and Complete the Merge

```bash
git add story-index.txt
git commit -m "Resolve merge conflict in story-index.txt"
```

---

## Push the Resolved Changes

```bash
git push origin master
```

---

## Verify via Gitea UI

Log in as `sarah` (`Sarah_pass123`) or `max` (`Max_pass123`) and confirm the latest commit and the corrected `story-index.txt` in the `story-blog` repository.
