# Day 026 - Git Manage Remotes

## 🎯 Objective

Add a new remote to an existing repository, commit a new file to `master`, and push the changes to that remote.

---

## Connect to the Storage Server

```bash
ssh natasha@ststor01
```

---

## Navigate to the Repository

```bash
cd /usr/kodekloudrepos/blog
```

---

## Add the New Remote

```bash
sudo git remote add dev_blog /opt/xfusioncorp_blog.git
```

---

## Verify the Remote

```bash
sudo git remote -v
```

---

## Switch to Master

```bash
sudo git switch master
```

---

## Copy the New File into the Repository

```bash
sudo cp /tmp/index.html .
```

---

## Stage and Commit the File

```bash
sudo git add index.html
sudo git commit -m "Add index.html to master branch"
```

---

## Push Changes to the New Remote

```bash
sudo git push dev_blog master
```

---

## Verify the Push

```bash
sudo git log --oneline
```

---
