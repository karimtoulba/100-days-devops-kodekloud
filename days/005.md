# Day 005 - SELinux Installation and Configuration

## 🎯 Objective

Install SELinux tools, check its status, and configure its operating mode.

---

## Install SELinux Tools

```bash
sudo yum update && sudo yum upgrade -y
sudo yum install selinux-basics selinux-utils policycoreutils -y
```

---

## Check SELinux Status

```bash
sestatus
```

---

## View Current Mode

```bash
getenforce
```

---

## Configure SELinux Mode (Persistent)

Edit the configuration file:

```bash
sudo nano /etc/selinux/config
```

Example:

```text
SELINUX=enforcing
```
