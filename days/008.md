# Day 008 - Install Ansible (yum install ansible)

**100 Days of DevOps, Day 8:** how to install Ansible via `yum` and confirm the installation, the first step toward configuration management and agentless automation.

## 🎯 Objective

Install Ansible and verify the installation was successful.

---

## Why This Matters

Ansible is one of the most widely used configuration management tools in DevOps because it's agentless — it only needs SSH access to a target host, with no software to install on the managed nodes themselves. Getting the control node set up correctly is the prerequisite for everything that follows: inventories, playbooks, roles, and eventually full infrastructure automation.

---

## Install Ansible

```bash
sudo yum install ansible -y
```

This installs Ansible and its dependencies from the configured `yum` repositories onto the control node.

---

## Verify the Installation

```bash
ansible --version
```

`ansible --version` prints the installed Ansible version along with the Python interpreter and config file paths it's using, confirming the install succeeded.

---

## Key Takeaways

- Ansible is agentless — it manages remote hosts purely over SSH, with no daemon required on the managed nodes.
- `ansible --version` is the quickest sanity check after installation, and it also reveals which config file and Python interpreter Ansible is using.
- This install step is the foundation for everything that follows in configuration management: inventories, ad-hoc commands, and playbooks.
