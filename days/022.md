# Day 022 - Clone Git Repository on Storage Server

## 🎯 Objective

Clone an existing bare Git repository into a working directory on the storage server for the development team to use.

---

## Connect to the Storage Server

```bash
ssh natasha@ststor01
```

---

## Clone the Repository

```bash
sudo git clone /opt/blog.git /usr/kodekloudrepos/blog
```

---

## Verify the Clone

```bash
cd /usr/kodekloudrepos/blog
git status
```

---
