# Day 035 - Install Docker Packages and Start Docker Service (CentOS/RHEL)

**100 Days of DevOps, Day 35:** how to install Docker CE on CentOS/RHEL using the official Docker repository, then enable and start the Docker service — the first step of the Container Fundamentals track.

## 🎯 Objective

Install Docker CE, the CLI, containerd, and the Buildx/Compose plugins on the app server, then enable and start the Docker service so containers can be built and run.

---

## Why This Matters

Docker packages aren't shipped in the default CentOS/RHEL repositories, so installing them requires adding Docker's own `yum` repository first. Getting this step right — repo setup, package selection, and enabling the service so it survives reboots — is the foundation every later container, Compose, and image-building task in this challenge builds on.

---

## Connect to the App Server

```bash
ssh banner@stapp03
```

---

## Install yum-utils

```bash
sudo yum install -y yum-utils
```

`yum-utils` provides `yum-config-manager`, which is needed to register Docker's repository with the system.

---

## Add the Docker Repository

```bash
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
```

This points `yum` at Docker's official CentOS repo so the `docker-ce` packages become installable.

---

## Install Docker Engine and Plugins

```bash
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

- `docker-ce` / `docker-ce-cli` — the Docker daemon and command-line client.
- `containerd.io` — the underlying container runtime Docker relies on.
- `docker-buildx-plugin` — adds multi-platform image build support (`docker buildx`).
- `docker-compose-plugin` — adds `docker compose` for multi-container apps.

---

## Enable and Start the Docker Service

```bash
sudo systemctl enable --now docker
```

`enable --now` both starts Docker immediately and configures it to start automatically on every future boot.

---

## Verify the Installation

```bash
sudo systemctl status docker
docker --version
```

---

## Key Takeaways

- Docker CE requires its own `yum` repo — it isn't in the default CentOS/RHEL package set.
- `docker-ce`, `docker-ce-cli`, and `containerd.io` are the minimum packages for a working Docker install; the Buildx and Compose plugins extend it with modern build and multi-container tooling.
- `systemctl enable --now` is the standard pattern for starting a service and persisting it across reboots in one command.
- `docker run hello-world` is the quickest sanity check that the daemon, networking, and image pulls all work.
