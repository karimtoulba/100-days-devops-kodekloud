# Day 019 - Install and Configure Web Application

## 🎯 Objective

Install Apache HTTP Server, configure it on a custom port, and deploy application content.

---

## Connect to the App Server

```bash
ssh steve@stapp02
```

---

## Update System Packages

```bash
yum update -y && yum upgrade -y
```

---

## Install Apache (httpd)

```bash
yum install httpd -y
```

---

## Enable and Start Apache

```bash
systemctl enable --now httpd
```

---

## Configure Custom Listen Port

```bash
vim /etc/httpd/conf/httpd.conf
```

Update the `Listen` directive:

```
Listen 8083
```

---

## Restart Apache

```bash
systemctl restart httpd
```

---

## Update the Default Page

```bash
vim /var/www/html/index.html
```

---

## Verify the Web Server

```bash
curl http://localhost:8083
```

---

## Deploy Application Content

```bash
sudo su
cp -r /home/thor/news /var/www/html/
cp -r /home/thor/games /var/www/html/
```

---

## Verify Deployed Content

```bash
curl http://localhost:8083/news/
curl http://localhost:8083/games/
```

---

✅ **Day 019 Complete**
