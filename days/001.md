# Day 001 - Linux User Setup with Non-Interactive Shell

## 🎯 Objective

Create Linux users and configure a service account with a non-interactive shell.

---

## Create a Regular User

```bash
sudo su
useradd devops
passwd devops
```

## Configure a Non-Interactive Shell

```bash
usermod -s /usr/sbin/nologin devops
/etc/passwd | grep devops
```
