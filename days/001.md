# Day 001 - Linux User Setup with Non-Interactive Shell (useradd, passwd, nologin)

**100 Days of DevOps, Day 1:** how to create a Linux user account and lock it down as a non-interactive service account using `useradd`, `passwd`, and `usermod -s /usr/sbin/nologin`.

## 🎯 Objective

Create a Linux user and configure a service account with a non-interactive shell, so it can own files and run processes but can never be used to log in interactively.

---

## Why This Matters

Service accounts (accounts used by applications, cron jobs, or daemons rather than humans) should never have an interactive login shell. If credentials for that account are ever compromised, an attacker can't get a shell — every login attempt is rejected. This is a standard Linux hardening practice used across RHEL, CentOS, Ubuntu, and Debian systems.

---

## Create a Regular User

```bash
sudo useradd devops
sudo passwd devops
```

- `useradd devops` creates the new Linux user `devops` with default home directory and shell.
- `passwd devops` sets (or resets) the account password.

---

## Configure a Non-Interactive Shell

```bash
sudo usermod -s /usr/sbin/nologin devops
```

`usermod -s /usr/sbin/nologin` changes the user's login shell to `nologin`. Any interactive login attempt (SSH, `su`, console) is refused with a "This account is currently not available" message, while the account remains fully usable for owning files and running background services.

---

## Verify the Configuration

```bash
cat /etc/passwd | grep devops
```

Expected output:

```
devops:x:1001:1001::/home/devops:/usr/sbin/nologin
```

The last field confirms the shell is set to `/usr/sbin/nologin` — the account cannot be used for interactive logins.

---

## Key Takeaways

- `useradd` + `passwd` create and secure a new Linux user.
- `usermod -s /usr/sbin/nologin` converts any account into a non-interactive service account.
- Checking `/etc/passwd` is the fastest way to confirm a user's configured shell.
- This pattern is a common Linux/DevOps interview and real-world sysadmin task.
