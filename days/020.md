# Day 020 - Configure Nginx + PHP-FPM Using Unix Sock

## 🎯 Objective

Install and configure Nginx and PHP-FPM to communicate over a Unix socket, then deploy a PHP-based application.

---

## Connect to the App Server

```bash
ssh banner@stapp03
```

---

## Install Nginx

```bash
sudo yum install nginx -y
```

---

## Install PHP-FPM

```bash
sudo dnf update -y sudo dnf upgrade -y
sudo dnf install -y epel-release
sudo dnf install -y http://rpms.remirepo.net/enterprise/remi-release-$(rpm -E %rhel).rpm
sudo dnf install -y dnf-utils
```

---

## Install PHP 8.2-FPM

```bash
dnf module reset php
dnf module install php:remi-8.1
dnf install php-fpm -y
php -v
```

---

## Configure PHP-FPM to Use a Unix Socket

```bash
sudo vim /etc/php-fpm.d/www.conf
```

Update the `listen` directive and ownership:

```
user = nginx
group = nginx
listen = /var/run/php-fpm/default.sock
listen.owner = nginx
listen.group = nginx
listen.mode = 0660
```

---

## Configure Nginx to Listen on Custom Port

```bash
sudo vim /etc/nginx/nginx.conf
```

Update the `server` block:

```nginx
server {
    listen 8095;
    root /var/www/html;
    index index.php index.html index.htm;

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/var/run/php-fpm/default.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

---

## Start/Enable Nginx and PHP-FPM

```bash
sudo systemctl enable --now nginx
sudo systemctl enable --now php-fpm
```

---

## Verify the Web Server

```bash
curl http://stapp03:8095/index.php
```
