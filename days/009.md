# Day 009 - MariaDB Troubleshooting

## 🎯 Objective

Troubleshoot a failed MariaDB service and restore it by fixing permission issues.

---

## Check Service Status

```bash
sudo systemctl status mariadb
```

---

## Check the Logs

```bash
sudo tail -30 /var/log/mariadb/mariadb.log
```

---

## Verify Directory Permissions

```bash
ls -ld /run/mariadb
```

The directory was owned by `root:mysql`, preventing the `mysql` user from writing to it. :contentReference[oaicite:1]{index=1}

---

## Fix the Ownership

```bash
sudo chown mysql:mysql /run/mariadb
```

---

## Restart MariaDB

```bash
sudo systemctl restart mariadb
```

---

## Verify the Service

```bash
sudo systemctl status mariadb
```

Expected:

```text
Active: active (running)
```
