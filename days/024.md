# Day 024 - Git Create Branches

## 🎯 Objective

Create a new feature branch from `master` in an existing shared repository on the storage server.

---

## Connect to the Storage Server

```bash
ssh natasha@ststor01
```

---

## Navigate to the Repository

```bash
cd /usr/kodekloudrepos/blog
```
---

## Switch to the Master Branch

```bash
sudo git switch master
```

---

## Create and Switch to the New Branch

```bash
sudo git branch xfusioncorp_blog
sudo git switch xfusioncorp_blog
```
