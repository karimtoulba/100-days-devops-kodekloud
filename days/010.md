# Day 010 - Linux Bash Scripts

## 🎯 Objective

Create a Bash script to back up a website directory, compress it into a ZIP archive, and copy it to a remote backup server using passwordless SSH. :contentReference[oaicite:0]{index=0}

---

## Create the Script

```bash
sudo mkdir -p /scripts
sudo nano /scripts/ecommerce_backup.sh
```

Add:

```bash
#!/bin/bash

SRC_DIR="/var/www/html/ecommerce"
BACKUP_DIR="/backup"
ARCHIVE="xfusioncorp_ecommerce.zip"
REMOTE_USER="clint"
REMOTE_HOST="stbkp01"
REMOTE_DIR="/backup"

zip -r "$BACKUP_DIR/$ARCHIVE" "$SRC_DIR"
scp "$BACKUP_DIR/$ARCHIVE" "$REMOTE_USER@$REMOTE_HOST:$REMOTE_DIR/"
```

:contentReference[oaicite:1]{index=1}

---

## Make the Script Executable

```bash
chmod +x /scripts/ecommerce_backup.sh
```

---

## Run the Script

```bash
/scripts/ecommerce_backup.sh
```

---

## Verify the Backup

Local:

```bash
ls -lh /backup
```

Remote:

```bash
ssh clint@stbkp01
ls -lh /backup
```
