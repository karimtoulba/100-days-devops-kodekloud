# Day 007 - Linux SSH Authentication (ssh-keygen, ssh-copy-id)

**100 Days of DevOps, Day 7:** how to configure SSH key-based authentication with `ssh-keygen` and `ssh-copy-id` for secure, passwordless login, and optionally disable password authentication entirely.

## 🎯 Objective

Configure SSH key-based authentication for secure, passwordless login between hosts.

---

## Why This Matters

SSH key pairs are more secure than password authentication because the private key never travels over the network and can't be brute-forced the way a password can. Key-based auth is also what makes automation possible — CI/CD pipelines, Ansible, and backup scripts all rely on passwordless SSH to connect to remote hosts non-interactively. Disabling password authentication afterward closes off an entire class of brute-force and credential-stuffing attacks against SSH.

---

## Generate an SSH Key Pair

```bash
ssh-keygen
```

`ssh-keygen` generates a new public/private key pair, saved by default to `~/.ssh/id_rsa` (private) and `~/.ssh/id_rsa.pub` (public).

---

## Copy the Public Key to the Remote Server

```bash
ssh-copy-id user@<server-ip>
```

`ssh-copy-id` appends the local public key to the remote user's `~/.ssh/authorized_keys` file, which is what allows the key (instead of a password) to authenticate future logins.

---

## Connect Using SSH

```bash
ssh user@<server-ip>
```

With the public key installed, this login should succeed without prompting for a password.

---

## Verify the Public Key

```bash
cat ~/.ssh/authorized_keys
```

This confirms the copied public key is present in the remote account's `authorized_keys` file.

---

## (Optional) Disable Password Authentication

Edit the SSH configuration:

```bash
sudo vim /etc/ssh/sshd_config
```

Set:

```text
PasswordAuthentication no
```

Setting `PasswordAuthentication no` forces every login to use key-based authentication, closing off password-guessing attacks against the SSH service entirely.

Restart SSH:

```bash
sudo systemctl restart sshd
```

As with any `sshd_config` change, the service must be restarted before the new setting takes effect.

---

## Key Takeaways

- `ssh-keygen` creates a key pair; `ssh-copy-id` installs the public half on a remote host's `authorized_keys`.
- Key-based authentication is what enables non-interactive automation tools like Ansible and CI/CD pipelines to connect over SSH.
- Disabling `PasswordAuthentication` after key setup removes brute-force and credential-stuffing as viable attack vectors.
- Always confirm key-based login works *before* disabling password authentication, to avoid locking yourself out.
