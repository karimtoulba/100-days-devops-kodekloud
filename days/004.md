# Day 004 - Script Execution Permissions

## 🎯 Objective

Learn how to make shell scripts executable and manage execution permissions.

---

## Create a Script

```bash
vim script.sh
```

Add:

```bash
#!/bin/bash
echo "Hello, DevOps!"
```

---

## Check Permissions

```bash
ls -la hello.sh
```

---

## Make the Script Executable

```bash
chmod +x hello.sh
```

---

## Run the Script

```bash
./hello.sh
```

Expected output:

```text
Hello, DevOps!
```
