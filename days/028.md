# Day 028 - Git Cherry Pick

## 🎯 Objective

A developer working on the `feature` branch has a single commit that needs to be applied to `master` without merging the entire branch. Use `git cherry-pick` to bring over just that commit.

---

## Connect to the Storage Server

```bash
ssh natasha@ststor01
```

---

## Navigate to the Repository

```bash
cd /usr/kodekloudrepos/blog
```

---

## Find the Commit on the Feature Branch

```bash
git switch feature
git log --oneline
```

Locate the commit hash for the commit with message `Update info.txt`.

---

## Switch to Master

```bash
git switch master
```

---

## Cherry-Pick the Commit

```bash
git cherry-pick <commit-hash>
```

---

## Verify the Commit Was Applied

```bash
git log --oneline
```

---

## Push the Changes

```bash
git push origin master
```

---
