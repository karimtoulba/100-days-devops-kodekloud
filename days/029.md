## Create the Pull Request

1. Open the repository in Gitea.
2. Switch to the `story/fox-and-grapes` branch.
3. Click **New Pull Request**, comparing `story/fox-and-grapes` into `master`.
4. Add a title/description for the PR.
5. Assign **tom** as the reviewer.
6. Submit the pull request.

## Review and Merge the Pull Request

1. Open the **Pull Requests** tab.
2. Open the PR submitted by Max.
3. Review the changes and add a comment.
4. Approve the review.
5. Click **Merge Pull Request**.
